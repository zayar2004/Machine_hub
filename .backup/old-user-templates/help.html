🔍 Machine ဘယ်လိုရှာမလဲ

  1. Home page မှာ ရှိသော search box ကို နှိပ်ပါ
  2. Machine name (ဥပမာ "Dream") သို့မဟုတ် code (ဥပမာ "DC001") ရိုက်ပါ
  3. Enter နှိပ်ပါ
  4. Result list ထဲက machine ကို နှိပ်ပါ
  5. Machine Detail မှာ Copy button ကို နှိပ်ပြီး code ကို copy လုပ်နိုင်ပါတယ်
💡 အကြံပြုချက်: Offline ဖြစ်နေရင်လည်း ရှာလို့ရပါတယ် — သင့် phone မှာ သိမ်းထားတဲ့ data ကနေ ရှာပေးပါမယ်။

⚠️ Error fix ဘယ်လိုရှာမလဲ

  1. Search box မှာ error code (ဥပမာ "E81") ရိုက်ပါ
  2. သို့မဟုတ် error name (ဥပမာ "Screen Error") ရိုက်ပါ
  3. Result ထဲက error ကို နှိပ်ပါ
  4. Error Detail မှာ fix steps နဲ့ photos တွေ ကြည့်နိုင်ပါတယ်

⭐ Favorite ဘယ်လိုထည့်မလဲ

  1. Machine သို့မဟုတ် Error detail page ကို ဖွင့်ပါ
  2. Favorite button ကို နှိပ်ပါ
  3. ကြယ်ပွင့် အဝါရောင် ဖြစ်သွားပါမယ်
  4. Drawer menu → Favorites မှာ အားလုံး စုစည်းထားပါတယ်

📱 App ကို phone မှာ Install လုပ်နည်း

  1. Chrome browser မှာ Machine Hub ကို ဖွင့်ပါ
  2. Chrome menu (⋮) ကို နှိပ်ပါ
  3. "Add to Home screen" ကို နှိပ်ပါ
  4. Confirm လုပ်ပါ
  5. Home screen မှာ Machine Hub icon ပေါ်လာပါမယ်
📌 Install လုပ်ပြီးရင် app ကို full-screen နဲ့ native app လို အသုံးပြုနိုင်ပါတယ်။ Browser UI မပါတော့ပါ။

🔄 Data ဘယ်လို update ဖြစ်လဲ

App ကို ဖွင့်တိုင်း သင့် phone က server နဲ့ automatic sync လုပ်ပါတယ်။ Top bar မှာ Synced လို့ ပြနေရင် data အားလုံး up-to-date ဖြစ်ပါတယ်။

  • 🟢 Synced — data up-to-date
  • 🟡 Syncing… — sync လုပ်နေဆဲ
  • ⚪ Online — network ရှိပေမဲ့ sync မလုပ်ရသေး
  • ⚫ Offline — network မရှိ (offline data ကို သုံးနေတယ်)

Sync ကို manual လုပ်ချင်ရင် topbar က indicator ကို နှိပ်ပါ။

❓ အခြားမေးခွန်းများ

Q: Machine မမြင်ရင် ဘယ်လိုလုပ်မလဲ?

သင့် account က သင့် shop ရဲ့ machine တွေကိုပဲ မြင်ရပါတယ်။ အကယ်၍ machine မပေါ်ရင် admin ကို ဆက်သွယ်ပါ။

Q: Photos ကို offline မှာ ကြည့်လို့ရလား?

ရပါတယ်။ Photo တစ်ခါ ကြည့်ပြီးရင် phone မှာ cache လုပ်ထားပြီး offline ဖြစ်လည်း ပြန်ကြည့်နိုင်ပါတယ်။

Q: Recent search ကို ဘယ်လိုရှင်းမလဲ?

Home page ရဲ့ Recent Search section မှာ Clear button ကို နှိပ်ပါ။
