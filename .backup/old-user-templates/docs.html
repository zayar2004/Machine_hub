1. Overview

Machine Hub က arcade / workplace technical staff များအတွက် machine knowledge နဲ့ error fix ကို လျင်မြန်စွာ ရှာနိုင်တဲ့ app ဖြစ်ပါတယ်။

  • Shop-based — သင့် shop ရဲ့ machine တွေကိုပဲ မြင်ရတယ်
  • Global errors — error knowledge က shop အားလုံး မြင်နိုင်တယ်
  • Offline-first — internet မရှိလည်း အလုပ်လုပ်တယ်
  • Photos — error တွေအတွက် ဓာတ်ပုံများ ပါဝင်တယ်

2. Search လုပ်နည်း

Universal Search

Home page ရဲ့ search box မှာ အောက်ပါအရာတွေ ရိုက်လို့ရပါတယ်:

  • Machine name — Dream
  • Machine code — DC001
  • Error code — E81
  • Error name — Screen
  • Error fix keyword — HDMI

Filter by Type

Search results page မှာ All, Machines, Errors ဆိုတဲ့ tabs တွေ ရှိပါတယ်။ တစ်မျိုးတည်း ကြည့်ချင်ရင် ရွေးပါ။

💡 Search က partial match ဖြစ်တဲ့အတွက် တစ်စိတ်တစ်ပိုင်း ရိုက်လည်း ရပါတယ်။ ဥပမာ Dre ရိုက်ရင် Dream Castle ပြနိုင်ပါတယ်။

3. Machine Detail

Machine Detail page မှာ အောက်ပါအရာတွေ ပါဝင်တယ်:

  • Machine name + code (code ကို copy လုပ်နိုင်တယ်)
  • Shop + Status (ACTIVE / INACTIVE)
  • Description
  • Related Errors — ဒီ machine နဲ့ ချိတ်ထားတဲ့ error များ
  • Repair History — ဒီ machine အတွက် repair log များ
  • Favorite button — favorite ထည့် / ဖျက်

Copy Button

Machine code ကို copy လုပ်ဖို့ code ဘေးက 📋 icon ကို နှိပ်ပါ။ Toast notification ပေါ်လာမယ်။

4. Error Detail

Error Detail page မှာ အောက်ပါအရာတွေ ပါဝင်တယ်:

  • Error code + name
  • Fix / Solution — ပြုပြင်နည်း (green card)
  • Explanation — ရှင်းလင်းချက်
  • Photos — error တွေအတွက် ဓာတ်ပုံများ
  • Related Machines — ဒီ error ဖြစ်နိုင်တဲ့ machine များ (သင့် shop ရဲ့ machine တွေပဲ ပြပါမယ်)
  • Favorite button
📌 Related Machines က သင့် shop ရဲ့ machine တွေပဲ ပြပါတယ်။ Admin ဖြစ်ရင် shop အားလုံးရဲ့ machine တွေ ပြပါမယ်။

5. Favorites

မကြာခဏသုံးတဲ့ machine / error တွေကို favorite ထည့်ထားပါ။ Drawer menu က Favorites မှာ အားလုံး စုစည်းထားပါမယ်။

  1. Machine သို့မဟုတ် Error detail page ကို ဖွင့်ပါ
  2. ⭐ Favorite button ကို နှိပ်ပါ
  3. ကြယ်ပွင့် အဝါရောင် ဖြစ်သွားမယ်
  4. ပြန်ဖျက်ချင်ရင် ထပ်နှိပ်ပါ

6. Offline အသုံးပြုနည်း

Machine Hub က offline-first ဖြစ်ပါတယ်။ Internet မရှိလည်း အောက်ပါအရာတွေ လုပ်နိုင်ပါတယ်:

  • Data ကြည့်ခြင်း (machine, error, photos)
  • Search လုပ်ခြင်း
  • Favorites ကြည့်ခြင်း
  • Recent search ကြည့်ခြင်း

Internet ပြန်ရလာရင် app က automatic sync လုပ်ပြီး အသစ်တွေ download လုပ်ပါမယ်။

7. App Install လုပ်နည်း

  1. Chrome browser မှာ Machine Hub ကို ဖွင့်ပါ
  2. Chrome menu (⋮) → Add to Home screen
  3. Confirm
  4. Home screen မှာ icon ပေါ်လာမယ်

Install ပြီးရင် app ကို full-screen နဲ့ native app လို အသုံးပြုနိုင်ပါတယ်။

8. FAQ

Q: Machine မမြင်ရင် ဘယ်လိုလုပ်မလဲ?

သင့် account က သင့် shop ရဲ့ machine တွေကိုပဲ မြင်ရပါတယ်။ Admin ကို ဆက်သွယ်ပါ။

Q: Photos offline မှာ ကြည့်လို့ရလား?

ရပါတယ်။ Photo တစ်ခါ ကြည့်ပြီးရင် cache လုပ်ထားပြီး offline ဖြစ်လည်း ကြည့်နိုင်ပါတယ်။

Q: Data က update ဖြစ်လား?

App ဖွင့်တိုင်း automatic sync လုပ်ပါတယ်။ Topbar မှာ Synced ပြနေရင် up-to-date ဖြစ်ပါတယ်။

Q: Password ပြောင်းချင်ရင်?

Admin ကို ဆက်သွယ်ပါ။ Admin က သင့် password ကို reset လုပ်နိုင်ပါတယ်။

Q: Recent search ကို ရှင်းချင်ရင်?

Home page ရဲ့ Recent Search section မှာ Clear button ကို နှိပ်ပါ။
