1. Overview

Machine Hub ဆိုတာ ဘာလဲ?
Arcade/workplace technical staff အတွက် machine knowledge နဲ့ error fix ကို လျင်မြန်စွာ ရှာနိုင်တဲ့ offline-first app။
အဓိက အချက် ၄ ချက်
  • Shop-based — ကိုယ့် shop ရဲ့ machine ပဲ မြင်
  • Global errors — error က ဆိုင်အားလုံး share
  • Offline-first — internet မရှိလည်း အလုပ်လုပ်
  • Photos — error fix အတွက် ဓာတ်ပုံ

2. Search လုပ်နည်း

ရှာနိုင်တဲ့ အရာများ
  • Machine name — Dream
  • Machine code — DC001
  • Error code — E81
  • Error name — Screen
  • Error fix keyword — HDMI
Filter by Type
Search page မှာ All, Machines, Errors — filter chips တွေ ရှိတယ်။
Multi-word Search
Dream Castle လို့ ရိုက်ရင် — ၂ လုံးလုံး ပါတဲ့ results တွေပဲ ပြမယ်။ Partial match လည်း ရ — Dre ရိုက်ရင် Dream ရှာတွေ့မယ်။

3. Machine Detail

ဘာတွေ ပါလဲ
  • Machine name + code
  • Shop code + status
  • Description
  • Known Errors — related errors
  • Repair History — repair log
Code Copy လုပ်နည်း
Machine code ကို copy လုပ်ဖို့ 📋 button ကို နှိပ်ပါ။ "Copied: DC001" toast ပေါ်လာမယ်။

4. Error Detail

ဘာတွေ ပါလဲ
  • Error code + name
  • Fix / Solution — ဖြေရှင်းနည်း (green card)
  • Explanation — ရှင်းလင်းချက်
  • Photos — error ရဲ့ ဓာတ်ပုံများ
  • Related Machines — သက်ဆိုင်တဲ့ စက်များ
Photos ကြည့်နည်း
Thumbnail ကို နှိပ်ပါ — full screen viewer ပေါ်လာမယ်။ Swipe (left/right) နဲ့ next/prev — ESC or ✕ နဲ့ ပြန်။

5. Favorites

သိမ်းနည်း
1. Machine or Error detail ကို ဖွင့်
2. ☆ Favorite button ကို နှိပ်
3. Star ဝါရောင် ဖြစ်လာမယ်
4. Sheet menu → Favorites မှာ ပြန်ကြည့်

6. Offline

Internet မရှိလည်း အလုပ်လုပ်
  • Search (cached data)
  • Machine detail
  • Error detail + fix
  • Photos (viewed before)
  • Favorites
  • Recent searches
Auto Sync
Internet ရလာတာနဲ့ auto sync ဖြစ်မယ်။ Topbar မှာ Syncing… → Synced ပြမယ်။

7. FAQ

Q: Machine မမြင်ရင်?
သင့် account က သင့် shop ရဲ့ machine တွေပဲ မြင်ရတယ်။ Admin ကို ဆက်သွယ်ပါ။
Q: Photos offline ကြည့်ရ?
Photo တစ်ခါ ကြည့်ပြီးရင် cache ဖြစ် — offline ဖြစ်လည်း ပြန်ကြည့်နိုင်။
Q: Password ပြောင်းချင်ရင်?
Admin ကို ဆက်သွယ်ပါ — Admin က သင့် password reset လုပ်နိုင်။
