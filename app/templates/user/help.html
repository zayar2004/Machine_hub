🔄 Sync & Offline အသုံးပြုနည်း

Sync ဘယ်လို အလုပ်လုပ်လဲ?
1. App ဖွင့်တာနဲ့ — first sync (auto) ဖြစ်တယ်
2. Data အားလုံး ဖုန်းထဲ (IndexedDB) သိမ်းတယ်
3. Internet မရှိလည်း သုံးလို့ရ
4. Data အသစ် လိုရင် — "Sync Now" နှိပ်ပါ
Data အသစ် လိုရင် Sync နှိပ်
Menu → Sync Status → Sync Now နှိပ်ပါ။
